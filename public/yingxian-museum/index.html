ABOUT THIS EXHIBIT

读懂结构，
也看见边界。

本展品以山西应县佛宫寺释迦塔为对象。常见文献记载其始建于辽清宁二年（1056），通高 67.31 米，外观五层六檐、平面八角。

本模型是程序化制作的科普结构示意，并非测绘模型。柱网、斗拱、暗层、材质与比例均有简化；爆炸视图不表示真实拆装工序。关于“不用一颗钉”的流行说法，本展仅说明主要木构连接的榫卯原理，不将其扩展为整座建筑完全不存在金属构件。

制作说明：Blender 分件建模与组装 → GLB → Three.js。Lux3D 因缺少 API 凭证未能提交生成；斗拱采用明确标注的程序化 Blender fallback。

参考资料：UNESCO · Wooden Structures of Liao Dynasty。精确构造应以实测与专业文献为准。
