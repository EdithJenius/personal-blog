# ROTOR LAB：视觉与运动教学原型

**不提供可加工尺寸；不能用于制造、维修、飞行安全或适航判断。** 这是从视频内图纸进行视觉推断的教学实验，不是逆向工程、制造级复原或飞控仿真。

## 输入与可确定结构

- 视频 7684559617875037440 的高分辨率第 13 帧，源帧 3766 × 2160。比较第 11、12、13、14、15、17 帧后选择无遮挡、正面展示的第 13 帧。
- 裁剪像素边界 (731,817) 至 (1367,1298)，不做生成式修复。图纸实际只占视频约 636 × 481 像素。
- 能辨认四叶布局、中心主轴、桨根变距组件、上下倾斜盘、拉杆、底部控制机构、爆炸图和零件表布局。

## 无法读取或验证

尺寸标注、单位、公差、配合、轴承规格、螺纹、材料牌号、热处理、载荷、真实桨型、阻尼、关节自由度和传动比均不可可靠读取。图纸存在生成图样式文字，不能把看似数字的笔画当作尺寸。

## 必须假设

- 全部长度为无量纲场景单位 u：桨尖半径约 5.44，主轴高度约 4.2，倾斜盘半径 0.9；为观察机构而缩短桨叶。
- 四个桨根每隔 90°，各以自身径向轴改变桨距。省略挥舞、摆振与弹性变形。
- θᵢ = collective + fore·cos(ψᵢ) + lateral·sin(ψᵢ)，角度单位度；ψᵢ = 转子方位 + i·90°。未模拟气动相位延迟。
- 倾斜盘俯仰 = −fore，横滚 = lateral；collective 每度抬升 0.025 u。上下盘共享倾斜，只有上盘局部绕主轴转动。
- 主轴转速用实际秒积分 rpm·2π/60，范围限制 0–90 rpm 便于观察，不代表真实飞行转速。
- 四组变距杆及三组控制杆每帧连接实际节点，杆件采用可伸缩示意，未求解恒杆长闭环运动学。可视连接正确不等同真实机构约束正确。
- 三个伺服均匀分布在 120° 方位，球铰、轴承和控制框架为示意结构。外壳指下部轴承护套。
- 爆炸沿轴向分离双盘与轮毂、沿径向分离四个桨根与伺服，连杆继续连接节点；不是可执行拆装顺序。

## 实现选择

Blender 数据 API 创建独立零件与层级；NLA 轨道将每个运动对象的动作按同名 clip 合并导出。GLB 根节点做 Z-up → Y-up 坐标变换，内部局部轴与 Blender 保持一致。网页直接加载该 GLB，实时控制与导出动画分别拥有变换写入权。

界面遵循用户指定浅灰实验台：#e7eae8 背景、#26352f 文字、钴蓝色旋转盘、铜橙色摇臂、黄色变距杆与红色下部控制杆。系统无衬线中文配合等宽数据。第一屏以模型为主，桌面侧栏、移动端下置控制。
